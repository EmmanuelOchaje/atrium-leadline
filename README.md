# Leadline

**Let the pool prove the depth.**

Leadline is a Uniswap v4 hook that turns a token issuer's market-making agreement into a mandate the pool enforces. The market maker can steer the issuer's liquidity but never take it; the hook measures the depth actually delivered ("Proof of Depth") and the market maker is paid only for the share of the target met.

## The Problem

Issuers pay market makers for depth, uptime and a tight spread but can't verify any of it. The market maker usually holds the inventory, and there's no way to prove what they're actually keeping near the price.

Fewer than 1% of protocols disclose market-maker terms.

## How It Works

1. **Charter.** Issuer writes a mandate: depth band (e.g. ±2%), target depth per side, uptime target, epoch length, and retainer.
2. **Custody.** Issuer deposits inventory + escrows the retainer. The hook holds the position (issuer can never be locked out).
3. **Steering.** Market maker steers the range (must contain the current price, within bounds, swap-free).
4. **Measurement.** On every swap, the hook accrues Proof of Depth: depth × time below and above the price inside the band.
5. **Settlement.** Each epoch closes: `payout = retainer × duration share × depth score`.
6. **Fallback.** Heartbeat stale past grace → anyone can `poke` the position into a wide fallback range.
7. **Handover.** Issuer can swap in an Understudy in one transaction.
8. **Recall.** Issuer can recall everything at any time; nothing can block it.

```bash
pnpm install

```

## Security Invariants

Each is enforced by contract logic and tested:

| # | Invariant | Enforced by |
|---|---|---|
| I1 | Custody — only issuer withdraws | No MM withdrawal path; pull payments |
| I2 | Pool binding — fixed PoolId per charter | Stored key, only createCharter takes external key |
| I3 | Caller auth — callbacks only from PoolManager | `onlyPoolManager`, `_unlocking` flag |
| I4 | Bounded steering — range always contains price | Validation on steer/createCharter |
| I5 | No swap path — MM can't swap inventory | Static: hook never calls swap |
| I6 | Conservation — balances match tracked state | Tracked idle + fees, invariant test |
| I7 | Honest measurement — only own liquidity counts | DepthMath uses only L; donations blocked |
| I8 | Bounded pay — score ∈ [0,10000], one close per epoch | Formula; `epochIndex` monotonic |
| I9 | Liveness — stale → anyone can poke | `poke` with grace check |
| I10 | Unblockable recall — no MM call on recall path | Pull-based owed, no receive() required |

See [SECURITY.md](./SECURITY.md) for the full checklist and test references.

## Key Design Decisions

- **Hook owns position:** `(owner = hook, salt = charterId)` means only the hook can steer; `noSelfCall` prevents re-entry.
- **One charter per pool (MVP):** Simplifies pool binding and state management.
- **Pull-based payments:** No external calls to MM on the recall path; MM claims via `claim(token)`.
- **Measurement at pool price:** DepthMath reads sqrtPriceX96 from the swap; no TWAP for MVP (stretch goal).
- **Fallback is passive:** Wide range, no steering required; anyone can trigger, issuer hands over.

## Limitations & Stretch Backlog

- Market maker can trade against the issuer's liquidity from a separate wallet (costs them fees + arbitrage).
- One position per charter; excess inventory sits idle between steers.
- Depth measured at current price, not TWAP (would prevent brief price manipulation).
- Market size unproven; real-world uptake unknown.

**Stretches:**
1. TWAP reference price for steering checks
2. Reserve position for leftover inventory
3. Market-maker bond with slashing
4. Net-sell caps per epoch
5. Reactive Network automation for `poke` and `settle`

## Hardening & Red Team

Eleven attack scenarios tested in [RedTeam.t.sol](./contracts/test/attacks/RedTeam.t.sol):

1. Withdraw inventory to MM ➜ `NotIssuer` ✓
2. Pull from pool directly ➜ PoolManager revert ✓
3. Steer far from price ➜ `RangeMustContainPrice` ✓
4. Steer razor-thin ➜ `RangeWidthOutOfBounds` ✓
5. Call unlock directly ➜ `UnauthorizedCallback` ✓
6. Wash-trade to fake score ➜ Fees moved, depth unchanged ✓
7. Donate to range ➜ `DonationsDisabled` ✓
8. Poke while alive ➜ `HeartbeatNotStale` ✓
9. Settle same epoch twice ➜ Idempotent ✓
10. Route through attacker pool ➜ Charter state untouched ✓
11. Block recall with revert ➜ Recall succeeds anyway ✓

See the UI "Notices to Mariners" panel for live attacks.
